Security
Auth Flow
1
Register or Login
Returns accessToken (15m) + refreshToken (7d). Refresh token stored in PostgreSQL sessions table.
2
Authenticate Requests
Pass Authorization: Bearer <accessToken> header on every request. Global JWT guard protects all routes. Use @Public() to opt out.
3
Token Rotation
When access token expires, call POST /auth/refresh with your refresh token. Returns a new access token AND a new refresh token (old one is invalidated).
4
WebSocket Auth
Pass JWT in socket.io handshake: { auth: { token: accessToken } }. Gateway validates on connect and registers presence in Redis.
